# 券商、数据源与 AI 服务接入

本页给出接入外部服务的统一流程。具体可用能力取决于当前版本、账户权限、地区和服务商策略；界面中显示的选项是部署实例的最终依据。

## 通用接入流程

1. 在服务商侧创建专用账户或应用，不复用个人主密钥。
2. 仅授予所需权限；先关闭提现、转账和不必要的交易权限。
3. 在“系统设置”对应页面保存凭证，不在聊天、截图、日志或 Git 中粘贴密钥。
4. 运行连接测试，确认时间、网络、代理和白名单。
5. 先查询账户和市场数据，再使用模拟环境完成小额或无风险验证。
6. 为连接设置负责人、到期提醒、轮换和撤销流程。

## 券商与交易所

| 类型 | 常见接入 | 关键前置条件 | 首次验收 |
| --- | --- | --- | --- |
| 美股 | Alpaca、IBKR、Futu/Moomoo OpenD、Webull OpenAPI、Tiger 等 | 地区与账户权限；部分连接需要本地网关 | 账户、现金、持仓、订单、模拟下单 |
| 港股 | Futu/Moomoo OpenD 等 | OpenD 运行与解锁状态 | 行情、持仓、订单和币种 |
| 加密资产 | 当前构建提供的交易所适配器 | API Key、Secret、IP 白名单、市场权限 | 时间同步、余额、交易对、模拟或最小订单 |

IBKR、Futu/Moomoo 等本地桌面网关必须与 QuantDinger 后端网络可达。容器访问宿主机时不要把 `127.0.0.1` 当作宿主机地址，应使用部署平台提供的宿主机地址并限制端口暴露。

正式启用前，请阅读[实盘交易安全](../trading/LIVE_TRADING_SAFETY_CN.md)。若对应中文页在当前版本不存在，请使用[英文版](../trading/LIVE_TRADING_SAFETY.md)。

## 数据与研究服务

系统可组合公共行情、宏观数据、标的池以及专业报告数据。建议按以下顺序验收：

1. 在“系统设置 → 专业报告数据”配置提供商。
2. 在“数据状态与同步”检查连接、同步时间、覆盖范围和错误。
3. 在“市场”确认标的、频率、时区和复权口径。
4. 在“AI 投研”生成一份小范围报告，核对数据质量与风险提示。
5. 对付费或限流服务设置用量预算、缓存和失败降级。

公开数据源可能有延迟、缺失或授权限制。生产决策应记录来源、时间戳和质量状态，不把单一公共数据源当作交易所级实时数据。

## AI / LLM

“系统设置 → AI / LLM”用于选择提供商、模型、API Key 和高级参数。当前界面可能提供 OpenAI、Google、DeepSeek、Grok、AtlasCloud、自定义 OpenAI 兼容服务等选项。

接入时：

- 选择服务商后再填写该服务商凭证和模型名。
- 自定义端点必须使用受信任的 HTTPS 地址，并验证其 OpenAI 兼容路径。
- 设置合理的超时、重试、并发和每日预算。
- 不向第三方模型发送未脱敏的账户、密钥、个人信息或受限市场数据。
- 运行一次最小研究任务，验证文本输出、结构化字段、错误处理和费用记录。

## 上线验收单

- 凭证已使用最小权限并完成轮换记录。
- 生产与测试凭证完全分离。
- 账户、持仓、订单、币种和时区显示正确。
- 模拟环境完成创建、暂停、恢复和异常处理。
- 连接中断、限流和密钥失效都有明确提示。
- 日志不包含 Secret、Token、完整账户号或个人信息。

发生问题时按[错误知识库](ERROR_KNOWLEDGE_BASE_CN.md)收集诊断信息。
