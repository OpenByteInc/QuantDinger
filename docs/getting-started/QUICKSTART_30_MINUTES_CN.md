# 30 分钟跑通 QuantDinger

这条路径面向刚完成安装的用户。目标不是一次配完所有功能，而是在不接触真实资金的前提下，完成登录、AI、行情、研究、策略和回测闭环。

## 开始前

- Web 页面与 `http://127.0.0.1:5000/api/health` 均可访问。
- 已准备一个可用的模型 API Key。
- 使用管理员账号，但不要在截图、Issue 或聊天中暴露密钥。
- 本教程只使用研究、回测和模拟/信号模式。

## 0～5 分钟：完成安全与产品模式

进入 **Settings**：

1. 在 **Product features** 中只开启需要的模块；个人部署通常不需要计费和公开注册。
2. 在 **Security & Authentication** 检查管理员、会话和登录策略。
3. 在 **Registration & Security** 关闭不需要的公开注册。
4. 保存后重新登录，确认设置生效。

如果是公网或 SaaS，请先完成[部署后首次设置](POST_INSTALL_SETUP_CN.md)，不要跳过域名、HTTPS 和备份。

## 5～10 分钟：配置 AI

进入 **Settings → AI / LLM**：

1. 选择一个模型提供商。
2. 只填写该提供商的 API Key、模型名和必要的 Base URL。
3. 高级超时和采样参数先保留默认值。
4. 保存并执行连接测试；失败时先看状态码和提供商余额。

模型提供商切换不会要求删除其他提供商配置。密钥只应保存在服务端。

## 10～15 分钟：检查数据

进入 **Settings → Professional report data** 和 **Data status & sync**：

- 选择目标市场需要的数据能力。
- 检查公共数据源或专业数据源是否可用。
- 确认最近同步时间、失败项和数据新鲜度。
- 不要用过期或不完整数据验证策略收益。

## 15～20 分钟：完成第一次研究

进入 **AI Research**：

1. 选择市场和标的。
2. 核对行情时间、币种和数据来源。
3. 运行分析并等待报告完成。
4. 查看数据质量、风险提示、证据引用和情景分析，而不只看结论。

详情见 [AI Research 使用指南](../product/AI_RESEARCH_CN.md)。

## 20～27 分钟：创建并回测策略

进入 **Strategy**，从 Strategy API V2 模板开始：

1. 选择与研究市场一致的模板。
2. 运行源码和 manifest 校验。
3. 保存新版本，记录策略目的和关键参数。
4. 进入 **Backtest**，选择日期、初始资金、手续费和滑点。
5. 运行回测并检查基准、最大回撤、成交记录、费用和数据警告。

不要只比较总收益。使用[回测中心指南](../product/BACKTEST_CENTER_CN.md)理解指标和限制。

## 27～30 分钟：建立安全下一步

- 保存研究报告、策略版本和回测结果。
- 配置一个通知渠道并发送测试消息。
- 如需连接账户，先使用模拟盘或只读凭据。
- 第一次部署使用 `signal`，不要直接切换 `live`。

## 完成标准

- 模型和数据源连接测试成功。
- 研究报告包含可追溯来源和数据质量信息。
- 策略通过校验并产生可解释的回测结果。
- 没有启用真实交易或提现权限。
- 知道去哪里查看日志、备份和错误知识库。
