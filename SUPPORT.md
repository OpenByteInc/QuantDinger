# Support

Use the channel that best matches your request so maintainers can respond efficiently.

## Documentation and self-service help

- Product and API documentation: <https://ai.quantdinger.com>
- Deployment guides: [docs/deployment](docs/deployment)
- AI Agent and MCP guides: [docs/agent](docs/agent)
- Strategy development guide: [docs/trading/STRATEGY_DEV_GUIDE.md](docs/trading/STRATEGY_DEV_GUIDE.md)

Search existing issues and discussions before opening a new request.

## Community support

- Use [GitHub Discussions](https://github.com/OpenByteInc/QuantDinger/discussions) for setup questions, usage guidance, and broad product or architecture discussions.
- Use the [support request template](https://github.com/OpenByteInc/QuantDinger/issues/new?template=community_support.md) when a reproducible repository issue is involved.
- Use [Telegram](https://t.me/quantdinger) or [Discord](https://discord.com/invite/tyx5B6TChr) for community conversation. These channels do not replace the issue tracker for reproducible defects.

## Bugs and feature requests

- Report reproducible defects with the bug report form.
- Submit scoped feature requests with the feature request form.
- Review the [public roadmap](https://github.com/orgs/OpenByteInc/projects/1) before proposing large changes.

## Security vulnerabilities

Do not disclose security vulnerabilities in a public issue or chat channel. Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Open source license compliance

For a license, notice, source-availability, or other open source compliance
inquiry, email <support@quantdinger.com> with subject
`[Open Source License]`. The public procedure and program scope are documented
in [docs/compliance](docs/compliance/README.md).

## Commercial support

For commercial licensing, deployment assistance, partnerships, or service-level support, email <support@quantdinger.com>.

## Safety notice

Never include API keys, private keys, credentials, account identifiers, personal data, or unredacted trading logs in public support requests. QuantDinger can submit real orders when live trading is enabled; reproduce issues with paper trading whenever possible.
